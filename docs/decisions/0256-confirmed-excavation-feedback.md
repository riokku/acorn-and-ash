# Confirmed excavation feedback

Digging changed terrain without a contact cue. Show a small burst of existing
dust and a short synthesized scrape only for new, nearby server-confirmed digs.
Full replacement lists and previously applied cuts stay silent. Limit each batch
to eight cues, attenuate by three-dimensional distance and respect reduced motion.
Stone/clay collection reuses dust; iron finds reuse the existing sparks.

Existing chopping contact prediction, tree recoil and inventory receipt counts
remain unchanged. Feedback audio voices register with the existing mute/pause
cleanup so neither excavation nor gathering tails leak across a hidden world.
No new asset, gameplay reward or simulation rule is introduced.
