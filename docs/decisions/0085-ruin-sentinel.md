# 0085 — A solo-friendly ruin sentinel

Existing ruin clearings now host one ruin sentinel instead of the ordinary warrior/mage pair. Wilderness sites, saved scenery and home ownership are unchanged. It uses the existing licensed animated warrior rig with original bone-attached crown and mossy shoulder pieces, a distinct sword and the existing readable attack/charge cues.

Solo toughness starts at 24 weighted blows. Each additional contributing character adds eight, capped at four characters. Spectators do not scale the fight, and reconnecting does not count the same character twice. Scaling never shrinks when helpers leave. Its slow, interruptible charged preparation, bounded damage and speed below player sprint preserve escape and careful solo play; no new defensive mechanic is introduced.

Each nearby living contributor receives private material piles and its existing next-unlearned housing blueprint roll. The first victory also drops one personal trophy, kept through knockout and placeable indoors or outdoors. That protected keepsake does not expire or get evicted by ordinary pile capacity pressure. A full backpack can collect it later. Victory records belong to the character/world and save in the same transaction as their protected rewards, so reconnecting cannot duplicate first trophies.

Boss maximum health travels in an additional compact server packet; ordinary raider packets and previous kind/item/buildable indices stay unchanged. The sentinel shares the warrior model template to avoid a duplicate download or template allocation. Player timing and cooperative difficulty still need real playtesting in the later balancing pass.
