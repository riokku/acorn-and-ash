# A quiet homecoming receipt

Returning to the player's own home now shows a dismissible fourteen-second
receipt of outdoor resources gathered and places discovered during this connected
outing. It uses confirmed collection events, never inventory deltas: chest
transfers, cooking, equipment swaps and login inventory are not counted as finds.

It describes what was gathered, not what is still carried. There is no new reward,
saved progression or claim button. Visiting another player's home does not end the
outing. Returning home consumes the memory; leaving hides the card. Reconnecting
or being knocked out clears the session memory without celebrating lost supplies.
The existing home arrival hint remains for quiet outings with nothing to recap.
