# Make the next home upgrade visible

The Home journal already offers building recipes, three useful yard projects and keepsakes. It did not clearly connect supplies brought home across outings to the next shelter tier.

Add a “Your next shelter” card above the existing projects. It shows the four earned home tiers, the next tier's existing benefits, individual material totals split between backpack and private home chest, missing amounts, and blueprint readiness. Progress caps each resource at its cost so excess logs cannot conceal missing sticks or bones. A ready card opens the existing upgrade placement preview; it never spends supplies itself.

First homes use carried materials only. Upgrades use the same combined home-supply helper as the existing build flow. Blueprint and indoor restrictions are presented separately from material progress. The final tier celebrates completion rather than inventing another purchase. No new costs, progression rules, assets or private-state messages are introduced.
