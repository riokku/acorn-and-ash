# River pools and narrow runs

The former channel mostly grew steadily toward the lake, with small bank variations. Its ripple speed responded to waterfalls but not channel width.

Use an irregular sequence of broad pools and constrictions, interpolated smoothly along the existing route. Keep the spring and lake endpoint widths, with independent smaller variations on each bank. Terrain carving, reeds, stones, depth contours, slough connections and placement clearance continue to use the shared channel dimensions. Water queries and reach bounds allow the larger footprint.

A shared flow pace varies inversely with the mean channel width, with bounded speeds and an additional waterfall boost. Both the river/slough ripple attributes and boat current use it. Existing bank and lake current fades retain calm slough interiors and still lake water.

This is a stylized current rather than a fluid simulation. Wider reaches take more valley space, and narrow reaches have faster drift; rowing upstream remains possible. Before/after images use the existing river-banks gallery and real terrain.
